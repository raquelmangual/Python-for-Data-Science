# Python for Data Science

A collection of Python code, scripts, and examples that I found helpful while earning my **Master of Science (MS) in Data Analytics**.

## About This Repository

This repository is a collection of Python code developed, adapted, and used throughout my graduate studies in Data Analytics.

The goal is to share useful code snippets, functions, and practical examples that can help students, aspiring data analysts, educators, and data science enthusiasts solve common analytical problems.

The code covers various aspects of the data analysis process, from data preparation and exploratory data analysis to statistical analysis and visualization.

Rather than serving as a structured course or comprehensive library, this repository is intended to be a growing collection of practical Python resources.

## Topics Covered

Code examples may include:

- **Data Cleaning and Preparation** — Handling missing values, duplicates, data types, and transformations.
- **Exploratory Data Analysis (EDA)** — Examining distributions, identifying patterns, and summarizing datasets.
- **Descriptive Statistics** — Calculating summary statistics and understanding data characteristics.
- **Statistical Analysis** — Applying statistical techniques to explore relationships and test hypotheses.
- **Data Visualization** — Creating charts and plots to communicate insights.
- **Outlier Detection** — Identifying unusual observations using techniques such as z-scores.
- **Python Functions and Utilities** — Reusable functions that simplify common data analysis tasks.
- **Machine Learning** — Examples of predictive modeling and model evaluation, where applicable.

## Getting Started

You can simply download a ZIP file containing all the scripts. Or...

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Navigate to the repository directory:

```bash
cd YOUR-REPOSITORY
```

Install the libraries needed for the examples you want to run. For example:

```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn jupyter
```

Individual scripts or notebooks may require additional dependencies.
